02 / UNDER THE PIXELS

How filters work

A / 10

Select a filter to explore its color transformations. Each effect applies simple, explainable operations to every pixel in the image.

Processing pipeline

  1. Load source pixels
  2. Apply color operations
  3. Blend with original

Formula used

C' = S(C × contrast + brightness + offset)

C = original RGB vector · S = saturation transform · clamp values to 0–255

Why it works

A filter changes pixel channel values in a consistent way, shifting the overall color and tone while preserving image structure.
